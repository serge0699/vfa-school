# 🎓 Основы функциональной верификации


## 🌍 Общее описание

**Основное назначение курса - освоение основных концепций функциональной верификации цифровых устройств** начинающим инженером. Курс состоит из 7 тем. В ходе освоения каждой темы обучающийся приобретает новые знания, которые наслаиваются на знания из предыдущих тем. Таким образом каждый раз формируется более полное представление.

**Каждое занятие строится в форме диалога. Вопросы и обсуждение категорически приветствуются.** Большинство теоретических знаний подкрепляются практическими примерами, которые доступны для запуска в ходе занятия. Также в ходе занятий, с целью закрепления полученных знаний, обучающиеся выполняют задания, которые проверяются преподавателем.

**"Артефактами" каждого занятия являются** задокументированные примеры и задания. Каждое занятие (кроме 1) начинается с повторения теории предыдущего занятия и ответов на вопросы обучающихся, сформулированных в ходе их самостоятельной работы.
